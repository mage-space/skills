# Face presets

The app's nine face presets. Each one is the prefix, a blank line, then the preset's text.

## Prefix

```
keep the reference's outfit, accessories, body, and setting exactly as shown. show them centered, facing the viewer directly. change the face to have:
```

## Presets

| Preset | Text |
|---|---|
| Cute | rounder cheeks, larger eyes, longer lashes, a smaller upturned nose, thinner softer brows, a smaller mouth with a subtle closed-mouth smile, a shorter jawline, smooth clear skin |
| Chiseled | a defined angular jawline, high prominent cheekbones, a straight narrow nose, a squared chin, thicker straight brows, tanned healthy skin, a neutral focused expression |
| Elegant | a longer narrower face, high cheekbones, a straight narrow nose, smooth poreless skin, a closed neutral mouth, a longer neck, even symmetrical features |
| Soft | a softer jawline, gentler arched brows, plush lips, smoother cheeks, a slightly rounder nose tip, bright healthy skin, a warm approachable expression |
| Sharp | sharper cheekbones, a slimmer nose bridge, stronger jaw definition, straighter brows, a more intense gaze, tighter facial structure, crisp symmetrical features |
| Doll | larger round eyes, a tiny refined nose, a smaller mouth, porcelain-smooth skin, softly rounded cheeks, very symmetrical features, a delicate polished expression |
| Rough | weathered tanned skin, fine lines around the eyes and mouth, short stubble, a heavy brow, a small scar across one brow, slightly chapped lips, a slightly crooked nose bridge |
| Freckled | dense freckles across the nose, cheeks, and forehead, warm sun-kissed skin, no makeup, lighter sun-bleached tips at the hairline |
| Mature | fine lines around the eyes and mouth, deeper nasolabial folds, fuller more defined adult features, grey at the temples, lived-in but healthy skin, a neutral composed expression |

## Example

The Freckled preset is sent as:

```
keep the reference's outfit, accessories, body, and setting exactly as shown. show them centered, facing the viewer directly. change the face to have:

dense freckles across the nose, cheeks, and forehead, warm sun-kissed skin, no makeup, lighter sun-bleached tips at the hairline
```

In the app, picking a preset fills the prompt box and the user can edit it before sending. So a preset can be adjusted ("Chiseled, but keep her smile"): start from the preset's text and change only what the user asked.
